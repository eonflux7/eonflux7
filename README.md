### Hi, I'm eonflux7

I work on engine ports, graphics upgrades and reverse engineering for older PC games, and on making capture
hardware behave better.

#### Featured

| Project | |
|---|---|
| [open-minidvr-50i](https://github.com/eonflux7/open-minidvr-50i) | Better video and audio for the mini DVR: 50i/60i fields, centred capture, no tearing, 31 kHz audio |
